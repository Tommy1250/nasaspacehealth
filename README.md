# nasaSpaceHealth
Repo for nasa space challenge 2026

# Install steps
1. Install [nodejs](https://nodejs.org/en/download) or [node version manager](https://github.com/nvm-windows/nvm/releases/latest) and [git](https://git-scm.com/install/windows) | for NVM you'll have to use
```bash
nvm install lts
nvm use lts
```
2. download the repo
```bash
git clone https://github.com/Tommy1250/nasaspacehealth
```
or from github desktop press clone repository and add `nasaspacehealth`

3. cd into the project folder
```
cd nasaspacehealth
```
4. Run your favorite IDE or text editor (for me vscode)
```
code .
```
5. install dependencies
```
npm install
```
6. Make your edits if any (optional)
7. Run the app
```
node .
```
